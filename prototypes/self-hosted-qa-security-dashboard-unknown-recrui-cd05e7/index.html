Competitive prototype

Self-Hosted QA & Security Dashboard

Open-source dashboard combining self-hosted QA tooling with automated security scanning for teams wanting full data control

Matching candidates with relevant Full Stack and Cybersecurity experience to client roles

Core features

  • Aggregates self-hosted QA tools (test runners, CI/CD, reporting) via awesome-selfhosted
  • Integrates Go-based security scanners from awesome-go for SAST/DAST/dependency checks
  • Exposes MCP server endpoints for AI-driven test orchestration and vulnerability triage

Differentiators

  • Fully self-hosted, no SaaS data egress
  • Modular plugin architecture using MCP for extensibility
  • Unified QA + security view in single pane

MVP plan

  1. Deploy awesome-selfhosted stack (Gitea, Drone, Grafana) on local k3s
  2. Wire Go security scanners (gosec, nuclei, trivy) into CI pipelines
  3. Implement MCP server wrapper for test triggering and result querying

Risks

  • Integration complexity across heterogeneous self-hosted tools
  • Maintenance burden of multiple upstream projects
  • Limited enterprise support vs commercial platforms
