Competitive prototype

AI Agent Attack Surface Mapper

Continuous discovery and ownership mapping of autonomous AI agents and their MCP server connections, closing the visibility gap left by EDR/CSPM tools that focus on traditional workloads.

Reveals the gap between reported AI inventory and actual running agents, providing visibility into agent ownership, deployment without security review, and unauthorized MCP server connections that create unmanaged attack surfaces.

Core features

  • Agent inventory with ownership attribution across cloud, SaaS, and on-prem
  • MCP server connection monitoring and risk scoring
  • Drift detection between approved agent registry and running instances

Differentiators

  • Purpose-built for autonomous AI agents, not generic processes or containers
  • Maps agent-to-MCP-server relationships and data flows
  • LangGraph-native telemetry for agent orchestration visibility

MVP plan

  1. Deploy sensorless discovery via cloud APIs and identity providers
  2. Correlate agent identities with MCP server endpoints using OpenTelemetry
  3. Build dashboard showing unowned agents and unauthorized MCP connections

Risks

  • EDR/CSPM vendors adding agent discovery modules
  • Enterprise reluctance to deploy new sensors for AI workloads
  • MCP standard evolution breaking connection parsing
